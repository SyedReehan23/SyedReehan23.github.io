Networked Multiplayer Unreal Engine • C++ • Multiplayer Networking

THE FLAG — Multiplayer Capture the Flag

A two-player Capture the Flag game built in Unreal Engine with C++, covering the full multiplayer flow — hosting and joining over LAN, a lobby, and a timed match where the server decides what actually happened.

Full session flow

Host or browse LAN games from the main menu, wait in a lobby, then both players travel into the match together without dropping their connection, carrying their team assignment across the map change.

Server-authoritative rules

Health, damage, flag steals, drops, returns and scoring are all decided on the server, so two clients can never disagree about the score.

Replicated state and RPCs

Health, team, flag state and the match timer replicate to every client and drive the HUD; firing goes to the server as an RPC, and death is multicast so every machine plays it.
